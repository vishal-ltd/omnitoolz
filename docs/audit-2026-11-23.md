# Project audit — 2026-11-23

Full audit of OmniToolz (62 browser tools after this pass): automated gates,
dependency advisories, license compliance, privacy claims, and a file-by-file
code review of every tool, shared component, pure library, script and config.
Every finding below was fixed in the same pass unless marked **accepted**.

## Method

- Gates: `tsc --noEmit`, `eslint`, `vitest`, `next build`, `scripts/smoke.mjs`
  (HTTP + security headers over every sitemap route), `scripts/render-check.mjs`
  (Puppeteer mounts every tool widget), `npm audit`.
- Review: three parallel slice reviews (PDF tools; images/media; app shell and
  infra) plus a direct review of developer/security/text tools and the
  signature verifier. Live deployment headers compared against repo config.

## Headline findings and fixes

### Licensing / supply chain
- **AGPL conflict (high).** `@imgly/background-removal` is AGPL-3.0 upstream;
  bundling it into served JS conflicted with the project's MIT license.
  **Decision (owner): remove the Background Remover.** Tool, registry entry,
  loader, dependency and the per-route `'unsafe-eval'` CSP exception removed;
  counts, copy, OG image and privacy policy updated. 62 tools remain.
- **Vendored engines without license/provenance (medium).** `public/libheif`
  (LGPL-3.0) and `public/qpdf` (Apache-2.0) shipped without license texts;
  libheif had no recorded version. Identified libheif as **libheif-js 1.23.5**
  by hash comparison against npm tarballs; added `LICENSE` files and provenance
  READMEs (version + SHA-256 + update procedure) for libheif, qpdf and pdf.js.
- **minimatch override broke ESLint plugins (medium).** A global `minimatch@11`
  override plus a postinstall source patch papered over a ReDoS advisory while
  breaking the callable-default API three plugins rely on. Replaced with one
  scoped override (`@typescript-eslint/typescript-estree → minimatch 11.0.1`,
  the only consumer in the advisory range that needs the named export);
  everything else resolves to audit-clean 3.1.5. **Postinstall patch deleted.**
- **Next.js advisories (moderate).** 15.5.28 → **15.5.29** (SVG optimizer bypass,
  edge-runtime cookie exposure, response injection; mostly inapplicable to this
  static Vercel deployment, fixed anyway). `npm audit`: **0 vulnerabilities**.

### Privacy / honesty
- Privacy policy §1 claimed "the only requests are the site's own app files"
  while OCR downloads from jsDelivr; §4 named the wrong CDN ("staticimgly").
  Rewritten to match reality; date bumped. About-page engine paragraph and
  roadmap copy corrected (audio tools shipped; touch-up removed with the tool).
- Tool outcome badges: extract-text/images/OCR said "Reads only — nothing is
  written" while producing files → new `extract` intent with honest badge.
  Compress PDF's lossless claim no longer contradicted by a "content is gone"
  warning (removed from `DROPS_CONTENT`).
- Edit PDF: white-out/existing-text edits now warn that covered text remains
  machine-readable (visual cover, not redaction), in UI and results note.
- Registry FAQs that described shipped features as "roadmap" (edit-pdf text
  editing, camera-scan enhance/auto-trim) rewritten to match the product.
- Hardcoded tool counts (about meta, package description, manifest) now derive
  from the registry; manifest moved to `src/app/manifest.ts` with light-theme
  `theme_color`. OG image regenerated ("62 free tools"); its source HTML moved
  out of `public/` and is reproducible via `npm run render:og`.

### Signature verifier (critical)
- Tamper detection reported **every genuine signed PDF as MODIFIED**: CMS
  attribute values were read from the SET wrapper instead of the inner value.
  Fixed (SET unwrapping), plus: `[0] EXPLICIT` SignedData unwrapping, certificate
  matched by issuer/serial instead of "first embedded", all signerInfos
  inspected, ByteRange whole-file coverage validated, DER length bounds hardened,
  ECDSA honestly disclosed, absolute UI claim softened to "covered bytes".
- The old test fixture was malformed CMS that certified the bug. Replaced with
  a real signature generated by `scripts/make-signed-fixture.mjs` (node-forge,
  dev-only); tests now assert exact signing time, crypto verify and tamper
  detection against it.

### PDF tools
- Compress: qpdf exit code checked (truncated output can no longer ship as
  "compressed"); savings math counts only actually-compressed bytes; engine
  failure distinguished from "already optimal"; rejected engine-load promise
  no longer cached forever.
- Clean: dates + XMP actually stripped; annotation removal keeps links, form
  widgets and orphan-free popups instead of wiping all Annots.
- Repair: encrypted inputs rejected with "unlock first" (object-stream repacking
  of encrypted strings corrupts content); failed files named in the result note.
- Protect: random owner password distinct from the open password, so permission
  toggles are no longer trivially bypassable.
- Invoice: items table paginates with repeated headers — printed totals always
  match visible rows; truncation shows ellipses; `roundMoney` fixed above the
  `Number.EPSILON` blind spot (8.005 → 8.01) with tests.
- Edit PDF: pdf.js documents destroyed on supersede/unmount; rotation- and
  CropBox-correct coordinate mapping (probe-verified against pdf.js for all four
  rotations, with no-regression proofs); aspect-correct image stamps; undo
  covers text commits and live property gestures; preview type scale matches
  the canvas; thumbnail pass aborts on file switch.
- Viewer (Read PDF): rewritten to lazy-render near-screen pages and release
  offscreen bitmaps (was retaining up to 150 full-res canvases ≈ GBs); aborts
  superseded loads; zoom works on mobile.
- Organize: touch long-press drag no longer reads nulled `currentTarget`;
  reorder detected in "changed" state; stale thumbnail loads can't overwrite
  newer state. Sign: load errors surfaced; marker offset aspect-correct.
- Thumbnails: try/finally destroy + abort checks before callbacks.
- Converters: WinAnsi sanitizing shared and actually complete (CJK/emoji no
  longer abort batches); Word paragraphs keep boundaries; XLSX sparse rows keep
  gaps and padding counts against the cell cap; CSV single-row bomb capped;
  `Math.max(...spread)` RangeError on big sheets fixed; pdf-to-word line
  grouping O(n) and x-ordered; compare-pdf hash collisions confirmed by text;
  image export refuses Columns≠Width, merges JPEG+SMask into PNG or skips
  honestly, SMask streams no longer exported as duplicate grey images.
- Smaller: split pre-validation syntax-only (no fake "1000 pages"), delete-pages
  placeholder hint, add-page-numbers clamp warning, rotate dead error path,
  camera-scan crop clamping + unmount URL revocation + false mirror comment.

### Images / media
- Screen recorder & audio trimmer: streams stopped on every failure path and on
  unmount (mic/camera indicators no longer stay on); double-start guards;
  AudioContext closed on decode failure and unmount; stale decode/playback
  races cancelled; stop-button InvalidStateError guarded.
- PNG/WebP → JPG composites on **white**, not black (compress + resize).
- HEIC: engine-load retry fixed; per-image WASM memory freed on failure;
  friendly decode errors; dimension validation.
- Target-size search: invalid scale steps can no longer infinite-loop;
  zero-byte targets rejected; canvas-limit guards added (image-core, resize);
  crop left/top off-by-one fixed; WAV truncated-fmt bounds check; ICO integer
  size validation.

### Developer / security / text
- Regex tester: every run in a worker with a 2s hard deadline and terminate on
  supersede/unmount — catastrophic backtracking can't freeze the tab.
- Hash: incremental SHA cores for chunked file hashing (constant memory),
  cross-checked against node:crypto in tests.
- JWT: object-shape validation, alg=none and empty-signature warnings, honest
  "never verified" framing; base64 tool whitespace/padding + clipboard failures;
  UUID/password generation confirmed unbiased crypto.getRandomValues; TOTP
  confirmed RFC 6238 with node:crypto cross-checks; word counter unicode-aware
  (code points, letter-property words); QR scanner camera lifecycle guarded.

### App shell / infra
- `useJob`: run token prevents stale runs committing over newer state; reset
  invalidates; pdf.js PasswordException/InvalidPDFException mapped to friendly
  sentences centrally. Results: async ZIP (no main-thread freeze), error path,
  object URLs created in effects.
- File queue: reducer-based (two adds in one tick can't exceed capacity),
  duplicate detection; file list stable keys (focus survives reorder), ARIA
  group; dropzone drag-leave flicker + folder message; window-level drop guard
  so stray drops can't navigate the tab away mid-job.
- Search dialog: proper combobox/listbox ARIA + body scroll lock; appearance
  panel focus restore; radio groups (theme/accent/segmented) get APG roving
  tabindex + arrow keys; SW cleanup only touches this app's worker/caches;
  error boundary logs + new `global-error.tsx`; recent tools use next/link;
  `navigator.userAgentData` with fallback; site URL normalization; dead search
  synonyms removed; unknown tool id renders an error, not an endless skeleton.
- Scripts: smoke picks a free port and asserts CSP/Permissions-Policy;
  render-check puppeteer fallback is cross-platform.
- CSP tightened: jsDelivr removed from `img-src`/`worker-src` (Tesseract spawns
  a blob worker); unpkg removed with the AGPL engine.

## Accepted (deliberate, not bugs)
- 8px `--text-display-xs` pixel type scale: intentional 16-bit aesthetic;
  WCAG sets no minimum size and contrast was verified in the UI pass.
- Shared pdf.js worker lives for the page lifetime (documented design);
  documents are destroyed per load.
- `docs/archive/plan.md` is marked archived design history, not live claims.
- Lighthouse scores in README are now labelled as measured during the UI pass,
  with reproduction instructions.
